`eng/prove-gates.ps1` creates its fixtures only under an OS-owned temporary directory, materializes the current working tree through the shared generated-directory pruner, runs the real conformance script against each fixture, asserts the expected exit codes, and removes only the resolved test-owned directory. The materialization proof does not consult Git, so modified and untracked inspection inputs remain in scope.

The compiler-based closure fixtures are generated by `eng/verify-record-closure.ps1`
under the existing ignored `artifacts/record-closure/` boundary. The full proof entry
and focused `eng/prove-gates.ps1 -Rule CS-002` use its `SelfTest` mode. Product mode
runs after the canonical Release build and inventories actual assembly metadata;
sources, diagnostics and results are retained, and no product object is constructed
through reflection or uninitialized storage. The four-assembly scope, pinned SDK,
allowed diagnostics and supported probe shapes fail closed when they change.
